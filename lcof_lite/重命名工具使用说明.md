# 重命名工具使用说明

## 概述

`rename_folders.py` 是一个用于管理题目文件夹名称的工具，可以为文件夹添加分类顺序前缀，也可以恢复原始名称。

## 当前状态

✅ **已完成重命名**：所有20个题目文件夹已按照学习顺序添加了前缀

文件夹命名格式：`序号-分类-原始名称`

例如：

-   `01-数组-面试题03. 数组中重复的数字`
-   `06-链表-面试题24. 反转链表`
-   `12-DP-面试题42. 连续子数组的最大和`

## 命令使用

### 1. 显示题目顺序

```bash
python rename_folders.py show
```

显示完整的学习顺序列表

### 2. 预览重命名

```bash
python rename_folders.py preview
```

预览将要执行的重命名操作，不实际修改文件夹

### 3. 执行重命名

```bash
python rename_folders.py rename
```

执行重命名操作（需要输入 `yes` 确认）

### 4. 恢复原始名称

```bash
python rename_folders.py restore
```

去掉所有前缀，恢复文件夹的原始名称（需要输入 `yes` 确认）

### 5. 查看帮助

```bash
python rename_folders.py help
```

显示完整的帮助信息

4. **快速定位**
    - 想练习某个类型时，快速找到对应题目
    - 序号便于记录学习进度

## 恢复原始名称

如果需要恢复原始名称（例如要提交到版本库，或觉得名字太长），可以运行：

```bash
python rename_folders.py restore
```

之后可以随时再次重命名：

```bash
python rename_folders.py rename
```

## 注意事项

1. **备份建议**

    - 虽然脚本很安全，但建议首次使用前备份整个 `lcof_lite` 文件夹

2. **编码问题**

    - Windows 控制台显示中文可能乱码，但实际文件名是正确的

3. **文件完整性**

    - 重命名只改变文件夹名称，不影响内部文件
    - README.md 和 Solution.py 等文件完全不受影响

4. **可逆操作**
    - 所有操作都是可逆的
    - 使用 `restore` 命令可以完全恢复原始状态

## 常见问题

### Q1: 为什么有些题目编号不连续？

A: 这是因为有些分类的题目数量不同，例如链表有4题（04-07），树只有1题（08）。

### Q2: 可以自定义顺序吗？

A: 可以！编辑 `rename_folders.py` 中的 `problems_order` 列表即可。

### Q3: 重命名后会影响代码运行吗？

A: 不会！文件夹重命名不影响内部文件的内容和结构。

### Q4: 如果只想重命名部分文件夹怎么办？

A: 编辑脚本中的 `problems_order` 列表，注释掉不需要的项。
