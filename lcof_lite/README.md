## 🚀 快速开始

### 1. 查看练习手册

```bash

```

**练习手册包含**：

-   📝 每道题的详细介绍

-   💡 为什么重要
-   📊 学习建议和时间安排
-   ✅ 刷题记录模板

### 2. 开始刷题

每个题目文件夹包含：

-   `README.md` - 题目描述、示例、题解

```bash

```

## 🎓 学习建议

### 做题三步法

1. **第一遍：理解思路**

    - 先独立思考 5-10 分钟
    - 看题解理解思路
    - 自己实现一遍（可以参考）

2. **第二遍：独立完成**

    - 不看题解，完全独立实现
    - 通过所有测试用例
    - 分析时间和空间复杂度

3. **第三遍：总结优化**
    - 总结解题模板
    - 尝试不同解法
    - 记录易错点和技巧

### 评估标准

**基础达标**（70%）

-   简单题：30 分钟内完成
-   中等题：45 分钟内完成

**优秀水平**（90%）

-   简单题：20 分钟内完成
-   中等题：30 分钟内完成
-   能分析复杂度

**专家水平**（100%）

-   简单题：10 分钟内完成
-   中等题：20 分钟内完成
-   能给出多种解法和优化

## 📝 常见问题

### Q1: 这 20 题够用吗？

**A**: 对于大多数笔试，这 20 题**足够**了。它们覆盖了 90% 的常考知识点。如果时间充裕，可以再刷完整版的 100+ 题。

### Q2: 要刷几遍？

**A**: 建议至少 **3 遍**：

-   第 1 遍：理解思路（可以看答案）
-   第 2 遍：独立完成（不看答案）
-   第 3 遍：快速复习（巩固记忆）

### Q3: 做不出来怎么办？

**A**:

1. 先独立思考 5-10 分钟
2. 如果没思路，直接看题解（不要浪费时间）
3. 理解后，自己重新实现
4. 过几天再做一遍

### Q4: Python 还是 C++？

**A**:

-   如果公司不限制语言，推荐 **Python**（代码简洁，面试时效率高）
-   如果要求 C++，本文件夹也包含 C++ 解法（`Solution.cpp`）

### Q5: 需要背答案吗？

**A**:

-   **不需要背**，但要理解思路和套路
-   重点是掌握**解题模板**和**思维方式**
-   做多了自然形成肌肉记忆
